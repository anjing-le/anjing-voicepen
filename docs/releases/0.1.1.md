VoicePen 0.1.1 是仓库历史重建后，供 macOS 干净机验收的首个可下载版本。

新增
- 使用全局快捷键完成录音、STT 转写、LLM 润色和剪贴板写入。
- 支持用户自行配置 OpenAI-compatible STT / LLM 服务，不需要 VoicePen 账号。
- 提供设置窗口、状态浮窗、系统托盘、主题和可选自动粘贴。
- 支持从 GitHub Releases 检查单一正式通道更新，展示更新要点并由用户决定是否安装。

可靠性与安全
- 语音处理采用单任务状态机，避免陈旧任务覆盖新结果。
- 更新包必须通过内置公钥签名验证；取消或失败不会强制覆盖当前版本。
- Provider 错误和诊断信息不会回显 API Key 或第三方响应正文。
- 首次未配置时自动打开设置，发现新版本时浮窗会提供克制提示。

注意事项
- macOS 安装包采用 ad-hoc code seal 且未经 Apple 公证；首次打开需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。请只从本项目官方 GitHub Release 下载，不要关闭 Gatekeeper 或执行绕过命令。
- API Key 由用户填写并保存在本机配置中，请勿上传配置文件或含 Key 的截图。
- 本版本用于建立干净安装基线；完整 OTA 验收需要后续更高版本从 0.1.1 执行升级。
